Fraktalz

the same z²+c workload on every backend your browser has — measured iterations, cross-checked, no estimates.
Workload: 1024×1024 tile, Seahorse Valley boundary, maxiter 5000.
Backends: JS fp64 (1 thread) · Web Workers fp64 (all cores) · WebGL2 fp32 · WebGL2 emulated fp64 (Dekker double-float — WebGL has no real doubles, so we build them from pairs of floats and measure what that costs).

Browsers deliberately anonymise hardware: the GPU name is bucketed to a generic "similar" card, the CPU model is never exposed, and the reported core count may be capped. The numbers are real; the labels are through frosted glass. The desktop bench tells the whole truth.

Iteration totals are read back from each backend and compared: JS is natively fp64, so it is the ground truth the emulated-double shader must match. Desktop version with native fp64 + AVX: github.com/ash23x/fraktalz
